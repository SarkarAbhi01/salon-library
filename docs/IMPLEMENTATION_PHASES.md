# Implementation phases

## Phase 1 — Foundation
- Monorepo, React/Vite, Express, Prisma, PostgreSQL.
- Environment template and responsive shell.

## Phase 2 — Authentication
- Login, forgot-password, reset-password, change-password.
- Role and tenant authorization.

## Phase 3 — SuperAdmin
- Tenant creation, owner credentials, status controls.
- Subscription/trial data model.
- Maintenance mode.
- Dashboard analytics/recent activity.

## Phase 4 — Salon
- Services and duration.
- Flexible pricing.
- Weekly morning/noon/evening windows.
- Emergency closure.
- Booking slot view.

## Phase 5 — Library
- Recurring batches.
- Capacity/seat availability.
- Student admission and monthly membership.
- Today batch view.

## Phase 6 — Public customer portals
- Salon customer search and slot booking.
- Library student self-registration, batch selection and seat reservation.

## Phase 7 — Payments and notifications
- Monthly subscription billing.
- Commission calculation.
- Customer invoices.
- Email/SMS/WhatsApp notifications.

## Phase 8 — Production hardening
- Automated tests, refresh sessions, security headers, audit viewer, backups, monitoring, CI/CD.
